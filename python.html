Chapitres et résumés

CHAPITRE 01

Généralités sur la programmation

Un algorithme décrit une solution sous forme d’étapes appliquées à des données. Un programme est la traduction de cet algorithme dans un langage et une syntaxe précis. La conception d’un logiciel passe par l’analyse des besoins, la conception, la programmation, les tests, le déploiement et la maintenance.

CHAPITRE 02

Mode de fonctionnement de Python

Python est un langage interprété et multiplateforme. Il possède des types de données, des conditions, des boucles, des fonctions, des objets et des modules. L’interpréteur permet d’exécuter les instructions Python.

CHAPITRE 03

Variables et types de données

Une variable associe un identificateur à une valeur. Python détermine automatiquement le type selon la valeur affectée. La fonction type() permet de connaître le type d’un objet et del permet de supprimer une référence à un objet.

CHAPITRE 04

Opérations et conversions

Les opérations permettent de calculer et de comparer les valeurs. Une conversion de type peut être nécessaire lorsqu’une donnée reçue doit être utilisée comme nombre ou comme texte. La fonction input() renvoie une chaîne qu’il faut convertir pour effectuer certains calculs.

CHAPITRE 05

Structures conditionnelles

Les branchements conditionnels permettent de choisir les instructions à exécuter selon une condition. En Python, on utilise if, elif et else. L’indentation délimite les blocs d’instructions.

CHAPITRE 06

Boucle for et séquences

La boucle for parcourt les éléments d’une séquence. range() génère une suite d’entiers : range(4) donne 0, 1, 2, 3 ; range(1,4) donne 1, 2, 3 ; range(0,5,2) donne 0, 2, 4. L’indentation doit être respectée. break arrête la boucle et continue passe à l’itération suivante.

CHAPITRE 07

Boucle while

La boucle while répète un bloc tant que sa condition reste vraie. Il faut initialiser les variables utilisées dans la condition et prévoir une mise à jour pour éviter une boucle infinie.

CHAPITRE 08

Fonctions et modules

Les fonctions regroupent des traitements réutilisables et rendent le programme plus lisible et plus facile à maintenir. Un module est un fichier .py qui regroupe des fonctions ou des éléments liés. La commande import permet de charger un module.
