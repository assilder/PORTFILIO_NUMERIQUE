JavaScript

Ajouter des interactions et des traitements dans une page Web.

Chapitres et résumés

Les résumés ci-dessous sont préparés à partir des documents de cours fournis.

CHAPITRE 01

Intégration de JavaScript

Le code JavaScript peut être écrit directement dans la page HTML avec la balise <script>, dans le head ou le body, ou dans un fichier externe portant l’extension .js.

CHAPITRE 02

Afficher des messages

La fonction alert() affiche un message dans une fenêtre. Le support présente également document.write() pour écrire du contenu dans le document et afficher du texte avec une variable.

CHAPITRE 03

Variables et types

Une variable stocke une information. let déclare une valeur modifiable et const une constante. Les types présentés sont String pour le texte, Number pour les nombres, Boolean pour vrai/faux et Null pour l’absence de valeur.

CHAPITRE 04

Opérateurs et conditions

Les opérateurs arithmétiques effectuent des calculs ; les opérateurs de comparaison comparent des valeurs. if exécute un bloc si la condition est vraie et else traite le cas contraire.

CHAPITRE 05

Boucles for et while

for répète un bloc un nombre déterminé de fois. while répète le bloc tant que la condition est vraie. Il faut faire évoluer la variable de contrôle pour que la boucle puisse s’arrêter.

CHAPITRE 06

Fonctions et tableaux

Une fonction regroupe des instructions réutilisables, peut recevoir des paramètres et retourner un résultat. Un tableau stocke plusieurs valeurs dans une variable ; son premier indice est 0.
