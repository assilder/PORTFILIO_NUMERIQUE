CSS

Mettre en forme les documents HTML avec les feuilles de style.

Chapitres et résumés

Les résumés ci-dessous sont préparés à partir des documents de cours fournis.

CHAPITRE 01

Introduction au CSS

CSS signifie Cascading Style Sheets, ou feuilles de style en cascade. Il décrit la présentation d’un document structuré HTML ou XML et permet de définir les couleurs, les polices et d’autres caractéristiques visuelles. Il sépare la structure HTML de la présentation.

CHAPITRE 02

Intégration des feuilles de style

Le CSS peut être interne, écrit dans une balise <style> dans l’en-tête HTML, ou externe, écrit dans un fichier .css relié avec la balise <link rel="stylesheet">.

CHAPITRE 03

Syntaxe et sélecteurs

La syntaxe générale est selecteur { propriété : valeur ; }. Le sélecteur désigne les éléments HTML concernés. Le cours présente les sélecteurs de balise et les sélecteurs de classe, définis avec un point avant le nom de la classe.

CHAPITRE 04

Classes et mise en forme

Une classe est un nom choisi par le développeur et associé à un élément avec l’attribut class. Plusieurs classes peuvent être appliquées simultanément pour combiner différentes propriétés de présentation.
